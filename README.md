## 🎯 What is Vibe Coding?

**Vibe Coding** is a modern software development methodology where engineers collaborate with AI systems to design, build, debug, optimize, test, deploy, and scale applications faster—while maintaining code quality and architectural integrity.

### The Vibe Coding Workflow

```mermaid
graph LR
    A[Describe Intent] --> B[AI Generates Code]
    B --> C[Review & Refine]
    C --> D[Test & Debug]
    D --> E[Deploy & Monitor]
    E --> F[Iterate & Scale]
    F --> A
```

### What Vibe Coding Is NOT ❌

- ❌ Copy-pasting AI code blindly
- ❌ Replacing engineering fundamentals
- ❌ Skipping architecture & design
- ❌ Avoiding debugging & testing
- ❌ Ignoring security best practices

### What You Need to Master ✅

| Skill Area | Why It Matters |
|------------|----------------|
| **Software Engineering** | Fundamentals never go out of style |
| **Prompt Engineering** | Communicate intent clearly to AI |
| **System Architecture** | Design scalable, maintainable systems |
| **Debugging** | AI makes mistakes; you fix them |
| **Infrastructure** | Deploy, monitor, and scale in production |
| **Product Thinking** | Build what users actually need |
| **AI Limitations** | Know when to trust (and when not to) |

> 💡 **Goal:** Build software faster while maintaining quality.

## 📊 The State of Vibe Coding (2026)

Vibe coding has moved from novelty to mainstream practice. Key data as of November 2026:

| Stat | Source |
|------|--------|
| ~42% of committed code is AI-generated or assisted | Sonar 2026 survey (1,149 pro developers) |
| 72% of developers use AI tools daily | Sonar 2026 |
| 72% say pure vibe coding is **not** part of their workflow | Stack Overflow 2025 |
| ~63% of vibe-coding platform users are **not developers** | Industry surveys (2026) |
| 1M+ pull requests generated by coding agents merged May–Sep 2025 | GitHub Octoverse 2025 |
| Lovable reached $100M ARR with 10M+ projects | July 2025 |
| 96% of developers do not fully trust AI-generated code | Sonar 2026 |
| 65% of vibe-coded production apps scanned had security issues (58% critical) | Escape.tech (1,400+ apps) |

**The real divide:** between *unverified output* and *accountable delivery*. Solo builders often judge apps by visible features; professional teams review every change, require tests, and limit agent access.

## 🤖 AI Tooling Ecosystem

### AI-Powered IDEs & Coding Agents

The winning 2026 pattern: pair an **in-editor assistant** (Cursor / Copilot) for autocomplete and quick edits with a **terminal agent** (Claude Code / Codex) for heavy autonomous work.

| Tool | Type | Best For | Pricing |
|------|------|----------|---------|
| **[Cursor](https://cursor.com)** | AI-first IDE | Daily feature work, Composer 2.5, parallel agents | Free tier / $20–200/mo |
| **[Claude Code](https://claude.com/code)** | Terminal agent | Deep repo work, long-running agentic tasks | $20–200/mo |
| **[OpenAI Codex](https://openai.com/codex)** | CLI + cloud agent | OpenAI-stack teams, delegated tasks | ChatGPT plans / API |
| **[Google Antigravity 2.0](https://antigravity.google)** | Agent-first platform | Multi-agent orchestration, browser testing | Free / ~$20 / $100 |
| **[GitHub Copilot](https://github.com/features/copilot)** | IDE agent | GitHub-native teams, lowest entry price | Free / $10–39/mo |
| **[Kiro](https://kiro.dev)** | Spec-driven IDE | Specs → design → tasks before code | $20–40/mo |
| **[Devin Desktop](https://devin.ai)** | IDE + cloud agents | Local + cloud agent delegation (ex-Windsurf) | Free tier / paid |
| **[Cline](https://cline.bot)** | VS Code extension + CLI | Open-source, bring-your-own-key | Free + API usage |
| **[OpenHands](https://openhands.dev)** | Open-source agent | Headless/CI automation, self-hosting | Free (MIT) |

### AI Chat Assistants (flagship / mid-tier / value)

| Model | Family | Best For | Context | Price (input/output per 1M) |
|-------|--------|----------|---------|-----------------------------|
| **Claude Opus 5.5** | Anthropic | Long-running agentic coding, hard multi-file work | 1M | $4 / $20 |
| **Claude Sonnet 5.5** | Anthropic | Everyday coding, best value mid-tier | 1M | $2 / $10 |
| **Claude Fable 5.1** | Anthropic | Hardest reasoning, long-horizon agentic work | 1M | $10 / $50 |
| **GPT-6 Astra** | OpenAI | Complex reasoning and coding flagship | ~1M | $10 / $50 |
| **GPT-6.1 Sol** | OpenAI | Near-Astra performance at lower cost | ~1M | ~$2–4 / $10–20 |
| **GPT-6.1 Terra** | OpenAI | Best value tier | ~1M | $2 / $10 |
| **Gemini 4 Argon** | Google | Real-world software engineering flagship | ~1M | ~$2 / $10 |

> 💡 **Model routing rule (2026):** route by task, not by habit. Complex multi-file/agentic work → flagship (Opus 5.5, Astra, Argon). Everyday coding → mid-tier (Sonnet 5.5, Sol, Flash). High-volume/repetitive steps → cheap/fast tier (Haiku 5.5, Luna, Terra, Flash-Lite).

### Local AI Setup

```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull current open-weight coding models
ollama pull deepseek-v4-flash
ollama pull glm-5.3
ollama pull kimi-k3

# Run with Open WebUI
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```

## 🎓 Getting Started

### Step 1: Set Up Your Environment

```bash
# Clone this repository
git clone https://github.com/yourusername/vibe-coding-zero-to-hero.git
cd vibe-coding-zero-to-hero

# Install essential tools
# - Git, Node.js, Docker
# - VS Code or Cursor
# - Ollama for local AI
```

### Step 2: Choose Your Learning Path

1. **Complete Beginner?** → Start with [02-how-to-start](./02-how-to-start/)
2. **Know basics?** → Jump to [07-prompt-engineering](./07-prompt-engineering/)
3. **Ready to build?** → Check [16-open-source-projects](./16-open-source-projects/)
4. **Want local AI?** → See [15-offline-vibe-coding](./15-offline-vibe-coding/)

### Step 3: Build Your First Project

Follow the project-based learning approach:

1. Pick a project from the roadmap
2. Use AI to generate initial code
3. Understand every line (don't copy-paste blindly!)
4. Debug issues with AI assistance
5. Deploy and share your work
